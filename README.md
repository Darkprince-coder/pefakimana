# PEFA Kimana

Website for PEFA Kimana (Pentecostal Evangelistic Fellowship of Africa), a church in Kajiado County, Kenya.

**Live:** [pefakimana.vercel.app](https://pefakimana.vercel.app/)

## Features

- Service times and weekly schedule (Sunday worship, Wednesday Bible study)
- Events calendar (youth convention, midweek Bible study, etc.)
- Sermon archive with video recordings and scripture references
- Ministry directory — worship, children's ministry, youth ministry, outreach
- Online giving portal for tithes and offerings
- Contact and location details

## Tech stack

- JavaScript / React
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```
